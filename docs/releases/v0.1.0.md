First release of **Spire Ledger**, a co-op stats mod for Slay the Spire 2 (fork of [Damage Charts](https://github.com/brian-gates/sts2-damage-charts), MIT). Tested on game v0.107.1.

### What it adds
- **Fair co-op attribution**: Poison and Doom damage is credited to the players who applied them, split by stacks applied. Both players' PCs record identical numbers.
- **Per-player stats** per fight and per run: damage dealt and taken, effects applied, block given to allies, block, healing, cards played, energy spent, damage per energy, biggest hit, potions.
- **Party table** (one row per player, best value in gold) in the combat stats (hotkey `C`) and the run recap.
- **End-of-run recap** on the game-over screen, with each player's badges.
- **Run history**: one JSON file per run in `%APPDATA%\SlayTheSpire2\SpireLedger\runs`, kept across save & continue.
- **Ledger** button in the Compendium: records, your runs, each run's party totals, badges and fights.
- UI in French or English, following the game language.

### Install
Unzip, copy `SpireLedger.dll` and `SpireLedger.json` into the game's `mods` folder (Steam > Slay the Spire 2 > Manage > Browse local files; create `mods` if missing), start the game and accept loading mods. **Both co-op players need the same version.**

With mods on, the game uses a separate save profile. To keep your unlocks (Daily Climb, characters), see `scripts/import-vanilla-progress.ps1` in the repository.

### Known limitations
- Tested in co-op on one PC (two local instances), not yet over Steam between two PCs.
- The bonus damage from Vulnerable is not yet credited to whoever applied it.
- Doom attribution uses the same logic as Poison but has not been tested in game.

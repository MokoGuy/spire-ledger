### Fixed: import reachable on an empty profile
The progress import was only reachable from the Ledger, inside the Compendium, which an empty modded profile hasn't unlocked yet. There is now an **Import progress** button right under the profile selector ("Profile N · click to change") on the main menu. It opens the import dialog, where you pick the source (no mods) and target (with mods) profiles.

### Install
Subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3831558895) (friends-only for now), or unzip and copy `SpireLedger.dll` and `SpireLedger.json` into the game's `mods` folder.

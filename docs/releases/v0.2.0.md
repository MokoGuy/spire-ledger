### New: one-click progress import
With mods on, Slay the Spire 2 uses a separate, empty save profile, so the Daily Climb, characters and Ascension are locked. Spire Ledger now fixes this itself:

- On the main menu, when your normal profile has more unlocks than the modded one, a dialog offers to **copy your normal progress** into the modded profile. Choose **Import**, then restart the game.
- The same action is in the **Ledger** screen (Compendium → Registre/Ledger), bottom right.
- The copy goes through the game's own save system, so the Steam Cloud copy is updated too. Your normal profile is never changed, and the previous modded progress is backed up in `%APPDATA%\SlayTheSpire2\SpireLedger\backups`.

### Clarified
Spire Ledger doesn't affect gameplay (`affects_gameplay: false`): a friend without it can still join your co-op run. Whoever has it sees the whole party's stats.

### Install
Subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3831558895) (friends-only for now), or unzip and copy `SpireLedger.dll` and `SpireLedger.json` into the game's `mods` folder.
